UI / UX Recommendations

Make it feel like a desktop tool

Typography

Use Inter, SF Pro, or Segoe UI for the shell at 13-15px. Reserve JetBrains Mono for JSON, variables, and console output. Keep screen titles compact, not hero-sized.

Color Contrast

Use navy for app chrome, royal blue for selected states and primary actions, silver for pane dividers, and red only for specific recoverable errors.

Spacing

Prefer split panes, row separators, and inspector sections over cards. Keep controls dense enough for repeated engineering work while preserving 8-12px internal rhythm.
